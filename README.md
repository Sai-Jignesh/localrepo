
# NOVA Bank

A modern, responsive front-end banking application built using HTML, CSS and JavaScript.

## Features

- Banking homepage and navigation
- Login and registration interfaces
- Password visibility controls
- Forgot password interface
- Customer dashboard
- Account balance visibility toggle
- Live dashboard date and time
- Demo money transfer form
- Transfer amount limit and fee calculator
- Transfer confirmation page
- Transaction history
- Transaction search and filtering
- Transaction sorting
- CSV statement download
- Printable transaction statement
- Beneficiary management
- Beneficiary search and removal confirmation
- Customer profile page
- Notification preferences
- Reset settings to defaults

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Browser Session Storage
- Git and GitHub

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Sai-Jignesh/localrepo.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser or use the Live Server extension.

## Important Note

NOVA Bank is an educational front-end demonstration project.

It does not connect to a real banking server, authenticate real customers, or perform actual financial transactions. All balances, customer details and transactions are sample data. Browser storage is used only for demonstration purposes.
