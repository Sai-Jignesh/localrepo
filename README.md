
# NOVA Bank

A modern banking application with a premium dark interface and gold accents.

## Features

- Banking homepage
- User login page
- User registration page
- Password visibility toggle
- Password confirmation validation
- Responsive authentication pages

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

